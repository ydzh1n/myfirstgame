# My First Game

Разработан прототип 2D-игры с видом сверху: персонаж бегает по арене, собирает
монеты, уворачивается от шипов и подбирает бонусы, стараясь набрать максимум очков.

## Управление

- Клавиатура (WASD / стрелки)
- Виртуальный on-screen джойстик
- Гироскоп (на мобильных устройствах)

## Основные фичи

- Плавное 2D-движение по двум осям на физике.
- Система жизней с перезапуском уровня при 0 жизней.
- Четыре типа элементов уровня: шипы (урон), монеты (очки), аптечки (+жизнь),
  бусты (временное ускорение).
- HUD: счёт, лучший результат (сохраняется между запусками), индикаторы жизней.
- Динамический спавн бонусов по таймеру с лимитом на карте.
- Screen shake при получении урона.
